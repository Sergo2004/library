# Техническое задание

## Цель проекта
Создание единой информационной системы библиотечного фонда города.

## Пользователи системы
- администратор;
- библиотекарь;
- читатель;
- аналитик.

## Основные модули
1. Авторизация и роли.
2. Управление фондом.
3. Учет читателей.
4. Выдача литературы.
5. Отчетность и аналитика.
6. Межбиблиотечный обмен.

## Нефункциональные требования
- веб-интерфейс;
- поддержка PostgreSQL;
- резервное копирование;
- журналирование действий;
- REST API.
