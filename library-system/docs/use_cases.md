# Сценарии использования

## Регистрация читателя
1. Библиотекарь вводит данные читателя.
2. Система проверяет уникальность.
3. Создается читательский билет.

## Выдача книги
1. Пользователь выбирает книгу.
2. Система проверяет наличие.
3. Формируется запись выдачи.
4. Уменьшается количество доступных экземпляров.

## Возврат книги
1. Библиотекарь оформляет возврат.
2. Система обновляет остаток.
3. При просрочке рассчитывается штраф.
