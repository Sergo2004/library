# Единая информационная система библиотечного фонда

## Назначение
Система предназначена для:
- автоматизации библиотечного фонда города;
- учета читателей;
- контроля выдачи и возврата литературы;
- анализа работы библиотек;
- формирования отчетности.

## Основные функции
- регистрация читателей;
- управление книжным фондом;
- выдача и возврат книг;
- учет штрафов и просрочек;
- аналитика популярности литературы;
- межбиблиотечный обмен;
- разграничение прав доступа.

## Технологии
Backend:
- Python
- Flask
- PostgreSQL
- SQLAlchemy

Frontend:
- React
- Axios
- Material UI
